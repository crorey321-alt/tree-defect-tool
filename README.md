# 교목 하자조사 도구 v20 — 설치·배포 안내

v19 HTML 파일을 **폰에 설치되는 앱(PWA)** 으로 바꾸고, **계정별 로그인 + 클라우드 동기화**를 붙인 버전입니다.

> **앱 주소**: <https://crorey321-alt.github.io/tree-defect-tool/>
> 지금 이 주소로 바로 쓸 수 있습니다(이 기기 전용 모드).
> 여러 폰에서 자료를 공유하려면 아래 **준비 A(Supabase)** 만 하시면 됩니다 — **남은 작업은 이것 하나뿐입니다.**

---

## 1. 왜 v19에서 폰이 먹통이 됐는가 (그리고 무엇을 고쳤는가)

| # | v19의 문제 | v20에서 한 일 | 효과 |
|---|---|---|---|
| 1 | 도면 PDF를 최대 20페이지까지 **전부 펼친 채 메모리에 보관**했습니다. 한 장당 약 19MB(압축이 풀린 상태)라 10페이지면 190MB, 20페이지면 380MB. 모바일 브라우저 탭 한도가 보통 200~400MB라 여기서 탭이 통째로 죽었습니다. | 압축된 상태로만 저장하고, **화면에 필요한 2페이지만** 펼쳐 둡니다(LRU). 페이지를 넘기면 오래된 것을 즉시 반납합니다. | **먹통의 가장 큰 원인 제거.** 6페이지 도면으로 실측한 결과 페이지 수와 무관하게 2장 상한이 유지됐고, 전체 PDF를 뽑는 동안에도 메모리는 6→8MB 수준이었습니다. |
| 2 | 되돌리기 기록이 **전체 데이터의 완전 복사본 60개**였고, 그 저장이 **입력창 타이핑 0.35초마다** 돌았습니다. | 되돌리기는 **현재 현장만, 20개**로 줄이고, 타이핑 중에는 기록하지 않습니다(마킹·삭제·항목 추가 같은 구조 변경에만). | 기록이 수백 건이어도 타이핑이 끊기지 않습니다. |
| 3 | pdf.js·jsPDF를 **외부 CDN에서 동기 로드**했습니다. 현장 신호가 약하면 화면이 안 뜹니다. | 라이브러리를 `lib/` 폴더에 **내장**하고 서비스워커로 캐시합니다. | **서버를 완전히 내린 상태에서 앱이 그대로 뜨고, 도면 렌더·PDF 생성까지 되는 것을 확인했습니다.** |
| 4 | 손가락을 움직일 때마다 전체를 다시 그리고, 마커마다 글자 폭을 다시 쟀습니다(마커 100개면 한 번에 300회). | 화면 갱신을 프레임 단위로 합치고, 글자 폭 측정 결과를 캐시합니다. | 마커가 많은 도면에서 이동·확대가 부드러워집니다. |
| 5 | 기록 전체를 **localStorage(5MB 한도)** 에 넣어, 한도를 넘으면 조용히 저장이 실패했습니다. | 저장소를 **IndexedDB**로 옮겼습니다(한도가 훨씬 큼). | 기록이 많아져도 저장 실패가 나지 않습니다. |

v19 데이터는 **처음 실행할 때 자동으로 넘어옵니다** (현장·수량표·기록·도면·사진 전부). 같은 브라우저에서 열면 됩니다.

## 1-2. 사진앱 연동 — 찍은 사진이 폰에도 남게 했습니다

v19에서는 앱 안에서 찍은 사진이 **앱 안에만** 들어가고, 폰 갤러리에는 남지 않았습니다.
기기에 남기려면 [촬영본 기기에 저장] 버튼을 **매번 손으로** 눌러야 했습니다.

**먼저 알아 두실 한계**: 웹앱은 폰의 카메라 폴더(DCIM)에 직접 쓸 수 없습니다. 브라우저 보안 정책이라
어떤 방법으로도 우회되지 않습니다. 그래서 기기별로 갈 수 있는 최선을 각각 다르게 넣었습니다.

| 기기 | v20 동작 | 사진이 남는 곳 |
|---|---|---|
| **갤럭시 · PC (크롬)** | **완전 자동.** 촬영하면 버튼을 누르지 않아도 기기에 바로 저장됩니다. | 다운로드 폴더 → 갤러리의 **Download 앨범** |
| **아이폰 (사파리)** | **탭 1번.** iOS는 공유창을 거치지 않으면 사진첩에 못 씁니다. 대신 여러 장을 모아 두었다가 **한 번의 탭으로 전부** 저장합니다. | **사진첩** |

### 켜고 끄기

상단 도구막대의 **[촬영본 자동 저장]** 체크박스로 켜고 끕니다(기본 켜짐, 기기에 기억됩니다).
데이터를 아끼거나 폰 저장공간이 빠듯할 때 끄면 됩니다.

### 미저장 표시

기기에 아직 안 넘어간 촬영본이 있으면 상단에 주황색 **[📱 미저장 N장]** 칩이 뜹니다.
**누르면 한 번에 저장**됩니다. 아이폰은 이 칩(또는 입력창의 [📱 촬영본 N장 사진첩에 저장] 버튼)이 주된 저장 방법입니다.

### 파일명

갤러리에서 바로 알아볼 수 있게 이름을 붙입니다.

```
교목하자_대명자이그랜드시티_20260806_No003_청단풍_1.jpg
```

`현장명_조사일자_번호_수종_순번` 순서입니다. 앱 안에 저장되는 사진(사진대지용 압축본)과 별개로,
**기기에는 카메라 원본 화질 그대로** 넘어갑니다.

### 알아두실 점

- 갤럭시에서 처음 저장할 때 크롬이 **"파일을 여러 개 다운로드하려고 합니다"** 를 한 번 묻습니다. **[허용]** 을 누르세요. 이후로는 다시 묻지 않습니다.
- 아이폰에서 저장하지 않은 채 앱을 완전히 닫으면 **기기 저장 대기분은 사라집니다.** (앱 안의 조사 사진은 그대로 남습니다 — 사진대지·백업에 영향 없음) 현장을 옮기기 전에 미저장 칩을 비워 두세요.
- 대기분은 최대 12장까지만 들고 있습니다. 넘으면 오래된 것부터 정리되며, 이때도 **조사 기록의 사진은 손대지 않습니다.**
- 아이폰에서 굳이 탭도 하기 싫다면: **폰 카메라 앱으로 먼저 찍고** → 앱에서 [🖼️ 사진첩 선택]으로 넣으면 됩니다. 이러면 사진첩에는 이미 들어가 있는 상태입니다.

## 2. 설치 순서

### 준비 A — Supabase 프로젝트 만들기 (한 번만, 10분)

1. <https://supabase.com> 가입 → **New project** 생성
   - Region은 **Northeast Asia (Seoul)** 을 고르면 빠릅니다.
   - Database Password는 따로 적어 두세요(앱에서는 안 쓰지만 분실하면 곤란합니다).
2. 왼쪽 메뉴 **SQL Editor** → **New query** → 이 폴더의 **`supabase-설치.sql`** 전체를 붙여넣고 **Run**
   - 테이블 `sites`, 저장소 버킷 `tds`, 그리고 **"내 자료만 보이게 하는 보안 규칙(RLS)"** 이 한 번에 만들어집니다.
3. 왼쪽 메뉴 **Project Settings → API** 에서 두 값을 복사
   - **Project URL**
   - **anon / public** 키 ← `service_role` 키는 **절대** 쓰지 마세요
4. 이 폴더의 **`config.js`** 를 열어 두 줄을 채웁니다.

   ```js
   window.TDS_CONFIG = {
     url: 'https://xxxxxxxx.supabase.co',
     key: 'eyJhbGciOi...'
   };
   ```

> **가입 메일 인증은 꺼 두었습니다** (2026-08-06). 가입하면 메일 확인 없이 바로 로그인됩니다.
>
> 왜 껐는가: Supabase 무료 플랜의 기본 메일 발송은 **1시간에 2~3통**이 한도(테스트용)라
> 가입을 몇 번만 시도해도 `email rate limit exceeded`가 뜨고 아무도 가입을 못 합니다.
> 팀원을 등록시킬 때마다 같은 벽에 부딪히므로 인증을 끄는 쪽이 실용적입니다.
>
> 대신 **아무 이메일 주소로나 가입이 됩니다.** 주소를 아는 사람만 들어오는 사내 도구라 큰 문제는 아니지만,
> 조사 자료는 여전히 계정별로 분리됩니다(RLS). 되돌리려면
> **Authentication → Sign In / Providers → Confirm email** 을 다시 켜면 되고,
> 제대로 인증 메일을 쓰려면 같은 화면에서 회사·네이버 SMTP를 연결하면 됩니다.

### 준비 B — 인터넷 주소에 올리기 ✅ 완료

PWA는 **https 주소**에서만 설치·오프라인 동작이 됩니다. 파일을 그냥 열면(`file://`) 안 됩니다.
**이미 GitHub Pages에 올려 두었습니다.**

| | |
|---|---|
| **앱 주소** | <https://crorey321-alt.github.io/tree-defect-tool/> |
| 저장소 | <https://github.com/crorey321-alt/tree-defect-tool> (Public) |
| 배포 방식 | `main` 브랜치의 root 폴더를 그대로 서빙 |

이 폴더(`Workspace\docs\2026-08-04-교목하자조사도구-v20`)가 곧 그 저장소입니다.

**앱을 고친 뒤 다시 올리는 법** — `sw.js`의 `CACHE` 숫자를 올린 다음:

```bash
cd "C:\Users\crore\Workspace\docs\2026-08-04-교목하자조사도구-v20"
git add -A
git commit -m "수정 내용"
git push
```

1~2분 뒤 반영됩니다. `CACHE` 숫자를 안 올리면 폰이 옛 버전을 계속 씁니다.

> 저장소가 Public이라 `config.js`의 anon 키가 공개됩니다. **이건 정상입니다** — anon 키는 원래 공개용이고,
> 실제 차단은 서버의 RLS 규칙이 합니다. 도면·사진·조사 자료는 저장소에 들어가지 않습니다.
> Private으로 두고 Pages를 쓰려면 GitHub 유료 플랜이 필요합니다.

### 준비 C — 폰에 설치

폰 브라우저에서 <https://crorey321-alt.github.io/tree-defect-tool/> 를 엽니다.

**아이폰 (Safari로 열어야 합니다. 크롬 아님)**
주소 열기 → 아래 **공유 버튼(↑)** → **홈 화면에 추가** → 추가

**갤럭시 (크롬)**
주소 열기 → 오른쪽 위 **⋮** → **앱 설치** 또는 **홈 화면에 추가**

설치하면 주소창 없이 앱처럼 열리고, 오프라인에서도 실행됩니다.

## 3. 사용

- 처음 화면에서 **회원가입** → 이메일·비밀번호로 계정을 만듭니다. 팀원은 각자 가입하면 됩니다.
- 로그인하면 **내 계정 자료만** 보입니다. 폰을 바꿔도 로그인하면 따라옵니다.
- 상단 **동기화** 칩을 누르면 즉시 동기화합니다. 평소에는 저장 후 자동으로 올라갑니다.
- 신호가 없는 현장에서는 그냥 쓰면 됩니다. **기기에 먼저 저장되고, 신호가 잡히면 알아서 올라갑니다.**
- 서버를 안 쓰고 싶으면 로그인 화면 아래 **"서버 없이 이 기기에서만 사용하기"** 를 누르면 됩니다.
- 사진은 [사진 촬영 / 첨부]로 넣습니다. **갤럭시는 찍는 즉시 폰에도 저장**되고, **아이폰은 상단 [📱 미저장] 칩을 한 번** 누르면 사진첩에 들어갑니다(위 1-2 참고).

## 4. 알아두실 점

- **주소는 뒷부분까지 전부** 필요합니다 — `https://crorey321-alt.github.io/tree-defect-tool/`. `crorey321-alt.github.io` 까지만 치면 404가 뜹니다. 북마크해 두세요.
- **비밀번호를 잊으면** Supabase 대시보드(Authentication → Users)에서 재설정해야 합니다. 앱에는 아직 "비밀번호 찾기" 화면이 없습니다.
- **무료 한도**: Supabase 무료 플랜은 저장소 1GB. 사진 한 장이 약 150KB이니 **대략 6,000장** 정도입니다. 넘으면 유료 전환이나 오래된 현장 정리가 필요합니다.
- **회사 자료 반출**: 도면과 현장 사진이 Supabase(해외 서버)에 올라갑니다. 앞서 말씀드린 대로 사내 보안 규정 확인이 필요한 부분입니다. Region을 Seoul로 잡아도 운영 주체는 해외 업체입니다.
- **백업**은 여전히 유효합니다. 서버와 별개로 [백업] 버튼으로 JSON 파일을 따로 보관해 두세요.
- 앱을 고쳐 다시 올릴 때는 **`sw.js` 위쪽의 `CACHE` 숫자를 하나 올리세요** (지금은 `tds-v20-2`). 안 올리면 폰이 옛 버전을 계속 씁니다.

## 5. 파일 구성

```
index.html               앱 본체
config.js                서버 주소·키 (여기만 채우면 됨)
manifest.webmanifest     앱 이름·아이콘 정의
sw.js                    오프라인 캐시 (고칠 때 버전 숫자 올리기)
icon-192.png / icon-512.png / icon-512-maskable.png
lib/                     pdf.js · jsPDF · Supabase (오프라인용 내장본)
supabase-설치.sql        서버 테이블·보안 규칙 생성 스크립트
```
